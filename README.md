# 🌦️ Weather Application

A sleek, intuitive, and responsive Weather Application designed to provide real-time weather updates, forecasts, and atmospheric insights. Built with modern software development practices, this application delivers accurate meteorological data wrapped in a clean, user-friendly interface.

---

## 🚀 Features

* **Real-Time Weather Updates:** Get instant access to current temperature, weather conditions, and localized atmospheric data.
* **Comprehensive Forecasts:** View extended hourly and daily forecasts to plan your schedule ahead.
* **Detailed Weather Metrics:** Tracks essential data including:
  * 🌡️ "Feels Like" temperature
  * 💨 Wind speed and direction
  * 💧 Humidity levels
  * 📉 Atmospheric pressure
  * 🌅 Sunrise and sunset timings
* **Dynamic Visuals:** Adaptive UI elements and iconography that change based on current weather conditions (sunny, rainy, snowy, stormy, etc.).
* **Search & Location History:** Easily search for any city globally and save your favorite locations for quick access.
